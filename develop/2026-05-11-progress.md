# 2026-05-11 工作进度

## 架构调整：Region-Driven → Span Control-Plane

### 灵感来源
- **CockroachDB PCR** 的 `PartitionedStreamClient` + `MergedSubscription` + periodic `PartitionSpans` 刷新
- **TiCDC** 的 `capture_regions` 动态订阅/退订 + `ChangeObserver` 机制
- 核心洞察：PCR 应该 **own spans（逻辑拓扑），而非 regions（物理拓扑）**

### 架构变化对比

| | 旧：Region-Driven | 新：Span Control-Plane |
|---|---|---|
| 拓扑感知 | 启动时发现 region 列表 → 固定订阅 | Span → PD resolve regions → 动态维护 |
| 新表 | 不支持（observer 注册遗漏） | DDL monitor → 自动创建 span → resolve → subscribe |
| Split | emit_pcr_split → 简单 subscribe 子 region | invalidate span → delta scan 补齐 → live stream → drain 父 region |
| 数据安全 | split race 必丢数据 | delta scan (since checkpoint_ts) 补全窗口 |
| 兜底 | 5s 周期性 rediscover | 30s periodic reconcile（降级为 safety net） |
| Schema 源 | 无 | info_schema（初始化）+ DDL job KV（运行时） |
